# 内置函数
语言提供了一些内置函数供使用  
包括很多方面  
## 运算
### 三角函数  
三角函数方面提供了**6**个，本质是原版的接口  
|  |正|反|  
|:-:|:-:|:-:|  
|正切|_m_tan()|_m_atan()|  
|正弦|_m_sin()|_m_asin()|
|余弦|_m_cos()|_m_acos()|

依照原版均为**角度制**  
#### 示例
~~~mls
var a = _m_tan(45); ~ 1
var b = _m_atan(1); ~ 45
~~~
#### 注意
由于mindustry自身浮点数处理机制  
会存在小误差  
比如`_m_sin(30)`得到的结果是`0.499999...`  
因此如果最后结果存在少量误差，为mindustry自身限制，并非语言解析错误
