# 语法
## 关键字
### ~
`~`是注释  
- 单行注释: `~`  
  跟在`~`后面的内容会被编译器忽视  
  **直到此行结束(即遇到\n) 或遇到下一个`~`**  
- 多行注释: `~~ ~~`  
  `~~ ~~`中间的内容会被编译器忽视  
> 使用示例稍后会在其他语法中体现，为了照顾0基础人群，这里不展示未讲解内容
### :
`:`关键字允许你使用原生逻辑  
`:`后的内容会被原封不动的加入结果  
每个`:`只能跟一个句子  
~~~mls
: op rand a 20;
: print "test";
~~~
### var
你可以使用var来声明一个变量  
并附上初始化值或不  
初始值可以是一个数，也可以是一个表达式  
但一个变量只能声明一次  
~~~mls
var a;  
var b = 10;  
var c = 4 + 1 / 2;  
var a = 3; ~ Error: " a " has been declared  
~~  
想改变它的值，再次赋值即可  
不进行初始化赋值时，自动初始化为null，请警惕这个值  
~~  
a = 63;
~~~
### if
使用if来进行条件判断  
条件为**真-true**则执行当前if的代码块  
条件为**假-false**则不执行，或继续判断其他分支  
- `if ($CONDITION) { $CODEBLOCK }`  
  这种会在检查条件`$CONDITION`后选择是否执行`$CODEBLOCK`   
~~~mls
var a = 10;
var b = 0;
if (a > 10) {
  b = 3;
}
if (a <= 10) {
  b = 8;
}
~~~
### while
while是**条件循环**  
条件为**真-true**则执行当前while的代码块  
条件为**假-false**则不执行  
- `while ($CONDITION) { $CODEBLOCK }`  
~~~mls
var a = 0;
while (a < 10) {
  a = a + 1;
} ~ 这个循环会在a等于10时退出
~~~
### for
for是**次数循环**  
条件为**真-true**则执行当前for的代码块  
条件为**假-false**则不执行  
- `for ($EXPRESSION;$CONDITION;$EXPRESSION) { $CODEBLOCK }`
~~~mls
var sum = 0;
for (var i = 0; i < 5; i = i + 1) {
    sum = sum + i;
    ~ var a = a + 1;
    ~~
    这个写法是错误的，会导致a被重复初始化，最后等于0 + 4 = 4
    而不是正确的0 + Σᵢ₌₀⁴ i = 10
    ~~
}
~~~
## 运算
### 基础运算
- `+`
- `-`
- `*`
- `/`
### 自增自减
- `++`
- `--`
~~~mls
var a = 10;
a--; ~ 9
a++; ~ 10
~~
这操作等价于a = a + 1;
--等同理
~~
~~~
### 复合赋值运算
- `+=`
- `-=`
- `*=`
- `/=`
~~~mls
var a = 10;
a += 10; ~ 20
~~
+=读作“加等于”
这操作等价于a = a + 10;
-=,*=等同理
~~
~~~
## 内置函数
语言提供了一些内置函数供使用  
包括很多方面
### 运算
#### 三角函数
三角函数方面提供了**6**个，本质是原版的接口  
|  |正|反|  
|:-:|:-:|:-:|  
|正切|_m_tan()|_m_atan()|  
|正弦|_m_sin()|_m_asin()|
|余弦|_m_cos()|_m_acos()|

依照原版均为**角度制**
##### 示例
~~~mls
var a = _m_tan(45); ~ 1
var b = _m_atan(1); ~ 45
~~~
##### 注意
由于mindustry自身浮点数处理机制  
会存在小误差  
比如`_m_sin(30)`得到的结果是`0.499999...`  
因此如果最后结果存在少量误差，为mindustry自身限制，并非语言解析错误
